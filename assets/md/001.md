## 2. 表音文字

ギリシア語の表記は表音的です．従って，各文字は音を表しました．
1. しかし，時代が下ると僅かな違いは無視され，発音が変化した音でも，古い綴が保持されることもありました．
2. 最終的に，ビザンチン時代以降は，多くの単語が表音的でなくなりました．

γはκ，γ，χそしてξの前で英語の “sing” の “ng” （又は日本語で「寝具」という時の「ん」）のように発音されました（鼻音のγ）．

## 4. 短母音と長母音

母音のεとοは常に短母音で，ηとωは常に長母音です．
つまり，前者2つよりも後者2つの文字のほうが長く発音されます．
一方で，α，ι，υの3つの母音は，短母音の場合と長母音の場合があります．
このページでは，これら3つが長母音の場合はマクロン付きで表し（ᾱ, ῑ, ῡ），
短母音の場合は，特別な記号を付けません．


## 5. 複母音

複母音（diphthongs, δί-φθογγοι）は下記のとおりです．

|    |    |    |    |    |    |    |
|----|----|----|----|----|----|----|
| αι | ει | οι | αυ | ευ | ου |    |	 
| ᾱι | ηι | ωι |    | ηυ | ωυ | υι |

1. 2つの文字は合わせて1音節ではありますが，それぞれの文字が音を持ちます．
しかし，時代が下り紀元前400年までには，ειとουは単純な音に変わりました．
即ち，ειはフランス語で “é” を長く発音した場合やドイツ語の “Seele” の “ee” と同様の音（「エー」のような音）となり，
ουは英語の “rule” の “u” や “food” の “oo” と同様の音（「ウー」のような音）になりました．
2. 更に時代が下ると，ᾱι，ηι，ωιのιは発音されなくなり，現在も通常発音されません（大学や学会の流儀によります）．
そのため，ιは一般的に長母音の文字の下に書かれ（**ᾳ, ῃ, ῳ**），下書きのイオータ（iota subscriptum）と呼ばれます．
ただし，長母音が大文字で書かれる場合は，長母音の後ろに書かれます（横書きのイオータ，iota adscriptum）．
- ΩΙΔHI = Ὠιδῆι = ᾠδῇ
- ΑΙΔHΣ = Ἅιδης = ᾅδης


## 6. 有気音

ギリシア語では母音は息の流れが音として伴う場合があります．
このような音を有気音や帯気音と呼びます（有気音でない母音を無気音と呼びます）．
有気音か無気音かは記号で表され，全ての語頭の母音と複母音にその記号が付されます．
有気音は「ʽ」で表され，hのような音が母音の前に添えられます（正確には英語のhとは異なります）．
無気音は「ʼ」で表され，単純な母音として発音されます．
現在の一般的な記法では，記号の位置は，大文字では前，小文字では上です．
ただし，複母音の場合は，2つめの文字に付されます．

- Ὁδός, ὁδός (hodos) 道
- Ἐξ, ἐξ (ex) 外へ
- Aὐτός, αὐτός (autos) 自分自身

しかし，複母音の2つ目の母音が下書きのイオータや横書きのイオータの場合，
有声音の記号は最初の文字に付き，には付きません．

- Ὠιδή, ᾠδή 歌

また，語頭のρは常に有声音記号を伴います．

- ῥήτωρ (rhetor) 雄弁家

語中でρが2つ続く場合，時折，ῤῥと書かれます．

- μύῤῥα myrra ミルラ

1. アッティカ方言における語頭のυは常に有声音です．

- ὕπνος 眠り


## 7. 初学者の発音について

今まで述べてきた発音は，Goodell(1902)内で，紀元前400年頃のアテーナイの発音に
限りなく近いと紹介されているものです．
一方で，ε, θ, φ, χの4つの文字は現在のギリシアに基づく発音が紹介されています．
これは，古代の音が初学者にとって理解を困難にしないためのGoodellの配慮です．
その他の点で（下書きのイオータを除いて），上記の発音は，当時のアテーナイ人とほぼ同じです．
